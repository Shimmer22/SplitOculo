# First-person video samples

This directory contains 10 first-person / POV video samples downloaded from
[Wikimedia Commons' First-person videos category](https://commons.wikimedia.org/wiki/Category:First-person_videos).

The original files were converted to H.264/AAC MP4 at approximately 480p and
15 FPS for lightweight experiments. The original source page and its license
should be checked before redistributing any file.

|---|---|
| `fp_01_airplane_takeoff.mp4` | Airplane takeoff |
| `fp_02_camden_park.mp4` | Camden Park POV |
| `fp_03_snowmobile.mp4` | Snowmobile in Yellowstone |
| `fp_04_horse_cart.mp4` | Horse and cart POV |
| `fp_05_railway_pov.mp4` | Railway onboard view |
| `fp_06_roller_coaster.mp4` | Roller coaster POV |

| `fp_10_motorcycle_pass.mp4` | Motorcycle crossing Tanglang-la Pass |
